Attention Is All You Need (Transformer)

拋棄傳統循環神經網路（RNN）與卷積結構，完全依賴多頭自注意力機制（Multi-Head Self-Attention）實現高度平行化的序列建模。

1. 核心問題與貢獻

在 2017 年以前，序列轉導任務（如機器翻譯）主要由 LSTM 與 GRU 等 RNN 架構主導。然而 RNN 必須依序計算隱藏狀態，導致長序列訓練難以平行化，且存在長距離依賴資訊衰減的問題。

核心突破：透過 Scaled Dot-Product Attention，任意兩個位置的 Token 都能在 O(1) 步長內直接計算關聯權重。

2. 關鍵架構組件

  • Scaled Dot-Product Attention：將 Query 與 Key 進行內積並除以維度平方根，避免 Softmax 進入梯度飽和區。
  • Multi-Head Attention：將向量投影到多個子空間平行計算注意力，讓模型同時捕捉語法結構與語意關聯。
  • Positional Encoding：由於缺乏循環結構，透過正弦與餘弦函數為輸入嵌入向量注入位置資訊。

3. 對後續研究的深遠影響

現代主流大型語言模型（如 GPT 系列與 DeepSeek-R1）皆沿用其 Decoder 架構，並針對推論階段的注意力計算衍生出 KV Cache 等核心最佳化技術。
