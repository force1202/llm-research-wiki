# 🧠 LLM Research Wiki

結合 **Karpathy LLM Wiki（持續累積式知識庫）** 與 **GitHub Pages** 的大型語言模型研究筆記網站。

## 專案特色
- **規則驅動開發 (`AGENTS.md`)**：明確定義目錄結構、HTML 模板、CSS 變數與雙向連結規範，讓 AI Agent 能持續依照相同標準新增頁面。
- **雙層架構**：`wiki/` 保存純文字 Markdown 筆記（支援 Obsidian），`docs/` 提供零建置依賴的靜態網頁。

## 本地預覽
直接用瀏覽器開啟 `docs/index.html` 即可瀏覽完整網站。
